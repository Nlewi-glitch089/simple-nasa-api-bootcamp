# NASA Astronomy Picture Lookup

A browser-based NASA Astronomy Picture of the Day exercise. Users can enter a date or choose from dates returned by NASA, then request the image or video and its description.

## Technology

HTML, CSS, JavaScript, NASA APOD API

## Run locally

Clone the repository, run `git switch answer`, and open `index.html` in a browser. The implementation uses NASA's public `DEMO_KEY`; it is rate-limited and intended for demonstration. For regular use, request a personal key from NASA and replace the demo key in `js/main.js`.

## Solution code

## Hosting
